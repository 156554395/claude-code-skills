# 微信表情包制作技能

帮助用户按照微信表情开放平台的规范制作表情包作品，并支持自动发布到微信表情开放平台。

## 快速开始

告诉 Claude 你想制作什么类型的微信表情包，例如：

- "帮我制作一套可爱猫咪的微信表情包，并发布到微信表情开放平台"
- "生成一组8张的动态表情，主题是开心的小狗，自动提交"
- "检查我的表情素材是否符合微信规范"

## 支持的功能

### 表情制作

- **静态表情**：PNG/JPG格式，240×240像素
- **动态表情**：GIF格式，240×240像素，循环播放
- **表情单品**：1张表情图（有限制）
- **表情专辑**：8～24张表情图

### 特效表情

- AR特效制作（24帧以内）
- 人脸跟踪特效
- 动作触发特效（张嘴、眨眼、点赞等）

### 配套素材

- 详情页横幅（750×400像素）
- 表情封面图（240×240像素，透明背景）
- 聊天面板图标（50×50像素，透明背景）

### 文案撰写

- 表情名称（不超过8个汉字）
- 表情介绍（不超过80个汉字）
- 表情含义词（不超过4个汉字）
- 版权信息

### 高级功能

- 表情形象创建
- 赞赏功能设置
- 付费功能配置

## 使用示例

### 示例1：制作一套8张的静态表情包

```
帮我制作一套8张的静态表情包，主题是一只橘猫，
表情包括：开心、难过、生气、惊讶、害羞、得意、疑惑、晚安
```

### 示例2：生成动态表情

```
制作一组16张的动态表情，主题是太空冒险的小兔子，
每个表情要有3秒左右的循环动画
```

### 示例3：检查规范

```
帮我检查这组图片是否符合微信表情的规范要求
[上传图片]
```

### 示例4：生成配套素材

```
我已经做好了表情图，帮我生成配套的横幅、封面图和图标
```

### 示例5：制作并自动发布

```
帮我制作一套橘猫表情包并自动发布到微信表情开放平台
```

技能会自动完成：
1. 生成所有表情素材
2. 处理图片尺寸和格式
3. 打开微信表情开放平台
4. 引导扫码登录
5. 自动上传素材并填写信息
6. 提交审核

## 审核要点提醒

### 必须满足

- 表情间有足够差异，不能只是文字不同
- 文字清晰，无错别字，使用文明用语
- 适合聊天场景使用
- 所有素材必须是原创或有授权

### 严格禁止

- 联系方式、二维码、银行账户
- 诱导分享、诱导下载
- 医疗、药品、烟草、酒类推广
- 暴力、色情、赌博内容
- 侵权素材（包括二次创作同人作品）

### 不建议包含

- 大段歌词、诗歌
- 广告、标语
- 过于宗教化的内容
- 政治敏感内容

## 提交流程

### 手动提交

1. 登录 [微信表情开放平台](https://sticker.weixin.qq.com)
2. 点击"提交表情"或"提交特效"
3. 按要求上传素材
4. 填写表情信息
5. 提交审核（通常5个工作日）

### 自动发布（使用 Playwright）

当你说"自动发布"或"帮我发布到微信表情开放平台"时，技能会：

1. **自动处理素材**
   - 裁剪图片到指定尺寸
   - 处理透明背景
   - 压缩文件大小

2. **打开浏览器登录**
   - 使用 Playwright 自动打开微信表情开放平台
   - 显示二维码等待你用手机微信扫码
   - 登录后继续自动化流程

3. **自动上传填写**
   - 上传所有表情图
   - 填写每张表情的含义词
   - 上传横幅、封面图、图标
   - 填写表情名称、介绍、版权信息
   - 选择标签

4. **提交审核**
   - 确认信息无误
   - 点击提交按钮
   - 显示提交结果

**注意**：登录环节需要你用手机微信扫码，其他步骤都可以自动完成。

## 常见问题

### Q: 表情审核需要多久？
A: 通常5个工作日内反馈审核结果。

### Q: 上架后可以修改吗？
A: 每自然月限用一次上架表情修改。

### Q: 付费表情有什么要求？
A: 需要至少有一套上架表情，且近三个月无违规。价格统一为10微信豆。

### Q: 为什么我的表情被驳回？
A: 常见原因包括：表情差异不足、含有违规内容、素材不符合规格、文案问题等。

### Q: 自动发布安全吗？
A: 自动发布使用 Playwright 浏览器自动化工具，只在你的本地设备运行，不会泄露你的账号信息。登录环节需要你本人扫码确认。

### Q: 自动发布需要准备什么？
A: 需要确保：
- 已安装 Playwright 相关工具
- 有稳定的网络连接
- 手机微信可用于扫码登录
- 素材已准备好并符合规范
