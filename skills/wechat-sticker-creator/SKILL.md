# 微信表情包制作技能

本技能帮助用户按照微信表情开放平台的规范制作表情包作品，并支持自动化发布到微信表情开放平台。

## 触发条件

当用户提到以下需求时触发本技能：
- 制作微信表情包
- 自动发布表情到微信表情开放平台
- 微信表情制作规范
- 提交表情到微信表情开放平台
- 生成符合微信规范的表情素材
- 表情审核相关问题
- 赞赏功能、付费功能设置

## 微信表情制作规范概要

### 1. 表情设计原则

1. **原创要求**：必须为设计者原创，或拥有版权
2. **场景适配**：适合微信聊天场景使用
3. **生动有趣**：表情应生动有趣
4. **审核合规**：不能违反《微信作品审核标准》

### 2. 表情素材规格要求

| 素材名称 | 数量 | 格式 | 尺寸（像素） | 文件大小 |
|---------|------|------|-------------|---------|
| 表情图 | 8～24 | 动态：GIF / 静态：PNG、JPG或GIF | 240×240 | ≤500KB |
| 详情页横幅 | 1 | PNG或JPG | 750×400 | ≤500KB |
| 表情封面图 | 1 | PNG | 240×240 | ≤500KB |
| 聊天面板图标 | 1 | PNG | 50×50 | ≤100KB |

### 3. 表情图素材要求

**动态表情**：
- GIF格式，240×240像素，≤500KB
- 须设置循环播放，节奏流畅不卡顿

**静态表情**：
- JPG、PNG或GIF格式，240×240像素，≤500KB

**通用要求**：
- 同一套表情须统一为动态或静态
- 数量：8～24张
- 风格统一，各表情图有足够差异
- 合理安排布局，避免过多留白

### 4. 详情页横幅要求

- JPG或PNG格式，750×400像素，≤500KB
- **避免出现任何文字信息**
- 色调活泼明朗，避免白色背景
- 横幅内容与表情相关，画面丰富有故事性
- 避免使用透明背景

### 5. 表情封面图要求

- PNG格式，240×240像素，≤500KB
- **须设置为透明背景**
- 使用最具辨识度的形象（建议半身或全身像）
- 无白色描边，无锯齿
- 不要出现正方形边框
- 画面简洁，避免装饰元素
- 除纯文字类型外，避免出现文字

### 6. 聊天页图标要求

- PNG格式，50×50像素，≤100KB
- **须设置为透明背景**
- 使用角色头部正面图像
- 无白色描边，无锯齿
- 画面简洁，避免装饰元素

### 7. 文案填写规范

**表情名称**：
- 不超过8个汉字，5个汉字以内最佳
- 不包含任何标点符号
- 中文名称避免空格
- 避免与已有表情专辑重名

**表情介绍**：
- 不超过80个汉字
- 充分展现形象特点或故事情节

**版权信息**：
- 不超过10个汉字
- 已注册版权的填写版权信息
- 未注册的填写设计师或工作室名称

**表情含义词**：
- 不超过4个汉字
- 尽量避免标点符号
- 同一套表情避免重复
- 使用普通话

### 8. 文字类表情特殊规范

1. 必须有动态或图案设计，突出创新性和趣味性
2. 不能只为满足动态要求做无意义的缩放、平移、晃动
3. 适用于聊天场景，大段歌词、诗歌、广告、标语不能通过审核

### 9. 特效表情规范

**素材要求**：
- 命名规则：名字+下划线+2位数字编号（如：ears_01.png）
- 帧数：24帧以内
- 格式：PNG
- 尺寸：480×480像素以内
- 文件大小：最大5MB，建议2MB以内
- 帧率：12帧/秒

**特效封面图**：
- PNG格式，透明背景
- 正方形，240×240像素以内
- ≤100KB
- 须与特效内容相关

**文案要求**：
- 特效名称：不超过8个汉字
- 字幕：不超过8个汉字
- 特效简介：不超过16个汉字
- 标签：每个不超过5个汉字，最多5个

### 10. 审核标准要点

**基本要求**：
- 富有创意，表意清晰
- 图片清晰，表情间有充分差异
- 文字清晰，无错别字，使用文明用语
- 适合聊天场景

**禁止内容**（包括但不限于）：
- 危害国家安全、破坏国家统一
- 煽动民族仇恨、破坏民族团结
- 宣扬邪教、封建迷信
- 含有强烈宗教性要素
- 散布淫秽、色情、赌博、暴力
- 歧视、丑化、侮辱或诽谤他人
- 诱导分享、诱导下载、诱导点击
- 联系方式、二维码、银行账户
- 医疗、药品、烟草、酒类等推广内容

**不建议内容**：
- 医疗、药品、美容、保健、减肥
- 招商加盟、金融、荐股、虚拟币
- 贷款、信用卡套现
- 武器、危险物品、博彩

### 11. 表情形象创建规范

**头像**：
- 1张，PNG格式，240×240像素，≤500KB
- 透明背景
- 建议半身或全身像

**聊天页图标**：
- 1张，PNG格式，50×50像素，≤100KB
- 透明背景
- 使用头部正面图像

**名称**：
- 不超过8个汉字
- 不包含标点符号
- 需对应具体角色形象

**简介**：
- 不超过80个汉字

### 12. 赞赏功能规范

**开通条件**：
1. 艺术家资料已审核通过
2. 个人账号绑定微信号/企业账号绑定微信支付商户号
3. 账号无违规行为
4. 上传符合要求的赞赏素材

**赞赏引导语**：
- **字数要求**：5-15个汉字
- **风格要求**：
  - 诙谐幽默、活泼有趣
  - 与表情主题强关联
  - 富有创意和互动性
- **文案原则**：
  - 避免生硬索要，用轻松口吻引导
  - 可以结合表情角色特点
  - 用问句、感叹句增强互动感
- **示例参考**：
  - "气泡狗如此可爱，发个赞赏可好？"
  - "喜欢这只胖橘吗？赞赏鼓励一下"
  - "表情包虽好，制作不易，求赞赏"
  - "给努力的小鸭子一点爱的鼓励吧"
  - "这表情太上头了，值得赞赏"
  - "用得开心就赏一个呗"

**赞赏引导图**：
- GIF或PNG格式，750×560像素，≤500KB
- **必须与表情主题相关**：每个表情包都需要生成定制化的赞赏引导图
- **设计要点**：
  - 展示表情角色可爱或有趣的一面
  - 风格与表情一致，避免透明背景
  - **背景要求**：避免使用白色或与白色接近的背景或边缘，使用明显的深色边缘或深色渐变背景
  - **文案要求**：诙谐幽默，与表情主题强关联
    - 示例1："快用打赏砸晕我，不信试试"
    - 示例2："喜欢这只胖橘吗？赞赏鼓励一下"
    - 示例3："表情包虽好，制作不易，求赞赏"
    - 示例4："给努力的小鸭子一点爱的鼓励吧"
  - 画面简洁明了，突出引导作用
  - 色彩活泼，与表情主题协调

**赞赏致谢图**：
- GIF或PNG格式，750×750像素，≤500KB
- **必须与表情主题相关**：每个表情包都需要生成定制化的赞赏致谢图
- **设计要点**：
  - 表达感谢的情感，风格与表情一致
  - 避免透明背景
  - **背景要求**：避免使用白色或与白色接近的背景或边缘，使用明显的深色边缘或深色渐变背景
  - **文案要求**：诙谐幽默，与表情主题强关联
    - 示例1："咣、咣，真的有点晕，还是要谢谢你~"
    - 示例2："谢谢支持！你太大方了"
    - 示例3："收到赞赏，开心到飞起"
    - 示例4："感谢鼓励，会继续努力的"
  - 角色可以做出感谢、鞠躬、比心、晕倒等有趣动作
  - 画面温馨感人，体现创作者用心
  - 建议使用明显的深色边缘或深色渐变背景，确保与微信详情页白色底色有清晰的视觉分隔

### 13. 付费功能规范

**开通条件**：
- 至少有一套上架的表情专辑
- 近三个月无违规行为

**价格**：
- 目前统一为每套10微信豆

**限制**：
- 付费表情和特效不可重复投稿到其他平台
- 已在其他平台上架的作品不可作为付费表情提交

## 工作流程

### 标准制作流程

当用户需要制作微信表情包时：

1. **需求确认**：确认用户想要制作的表情类型（静态/动态/特效）
2. **主题设计**：帮助用户确定表情主题、角色形象
3. **素材生成**：生成符合微信规范的图片素材
4. **图片下载与尺寸调整**：
   - **第一步：生成高清素材**
     - 使用AI图片生成工具创建2048×2048像素的高清表情图片
     - 生成时使用高分辨率确保细节清晰
     - 提示词中明确指定尺寸要求
   - **第二步：下载到本地**
     - 下载所有生成的2048×2048高清图片到本地目录
     - 确保文件命名符合规范（如：sticker_01.png, sticker_02.png）
   - **第三步：使用sips调整尺寸**
     - 将2048×2048的高清图片调整为240×240的微信表情标准尺寸
     - 使用 `sips` 工具直接覆盖原文件：
       ```bash
       # 表情图：从2048×2048调整为240×240
       sips -z 240 240 sticker_01.png

       # 详情页横幅：从2048×2048调整为750×400
       sips -z 400 750 banner.jpg

       # 封面图：从2048×2048调整为240×240
       sips -z 240 240 cover.png

       # 图标：从2048×2048调整为50×50
       sips -z 50 50 icon.png
       ```
     - 注意：`sips -z 高度 宽度` 参数顺序是高度在前，宽度在后
     - **为什么要先高清再缩小**：
       - 2048×2048的高清源图能保留更多细节
       - 缩小后图片更清晰，不会出现模糊或锯齿
       - 后续如需其他尺寸可从高清源图重新调整
       - AI生成高分辨率图片质量更好
   - **第四步：验证调整结果**
     - 使用 `sips -g pixelWidth -g pixelHeight` 检查调整后的尺寸
     - 确保文件大小符合要求（表情图≤500KB，图标≤100KB）
5. **文案撰写**：编写表情名称、介绍、含义词等文案
6. **赞赏功能配置**（可选）：
   - **赞赏引导语生成**：
     - 根据表情主题生成5-15个汉字的引导语
     - 风格诙谐幽默，与表情强关联
     - 示例："这只胖橘超可爱，值得赞赏鼓励"
   - **赞赏引导图制作**（必须与表情主题相关）：
     - 尺寸：750×560像素，GIF或PNG格式，≤500KB
     - 根据表情角色形象定制设计
     - 示例文案："快用打赏砸晕我，不信试试"
     - 使用深色渐变背景，避免白色边缘
   - **赞赏致谢图制作**（必须与表情主题相关）：
     - 尺寸：750×750像素，GIF或PNG格式，≤500KB
     - 根据表情角色形象定制设计
     - 示例文案："咣、咣，真的有点晕，还是要谢谢你~"
     - 使用深色渐变背景，避免白色边缘
7. **审核检查**：检查素材和文案是否符合审核标准

### 自动发布流程（使用Playwright）

当用户要求自动发布到微信表情开放平台时：

1. **素材预处理**：
   - **第一步：生成并下载高清素材**
     - 使用AI工具生成2048×2048像素的高清表情图片
     - 下载所有高清图片到本地目录
   - **第二步：使用sips调整尺寸**
     - 将2048×2048的高清图片调整为微信标准尺寸
     - 表情图：`sips -z 240 240 sticker_01.png`（从2048×2048调整）
     - 横幅：`sips -z 400 750 banner.jpg`
     - 封面：`sips -z 240 240 cover.png`
     - 图标：`sips -z 50 50 icon.png`
   - **第三步：验证调整结果**
     - 使用 `sips -g pixelWidth -g pixelHeight` 检查尺寸
     - 确保符合规范：表情图240×240、横幅750×400、封面240×240、图标50×50
     - 检查文件大小：表情图≤500KB、图标≤100KB
   - 处理透明背景（封面图、图标）
   - 压缩文件大小到限制范围内
   - 重命名文件符合规范

2. **登录平台**：
   - 使用 Playwright 打开 https://sticker.weixin.qq.com
   - 扫描二维码登录（需要用户手机扫码）
   - 等待登录完成

3. **进入提交页面**：
   - 点击"提交表情"按钮
   - 进入表情上传页面

4. **上传表情图**：
   - 按顺序上传8-24张表情图
   - 为每张表情填写含义词
   - 选择对应的表情标签

5. **上传配套素材**：
   - 上传详情页横幅（750×400，≤500KB）
   - 上传表情封面图（240×240，≤500KB，透明背景）
   - 上传聊天面板图标（50×50，≤100KB，透明背景）

6. **赞赏功能设置**（可选）：
   - 开启赞赏功能开关
   - 输入赞赏引导语（5-15个汉字）
   - 上传赞赏引导图（750×560，≤500KB）
   - 上传赞赏致谢图（750×750，≤500KB）

7. **填写基本信息**：
   - 输入表情名称（不超过8个汉字）
   - 输入表情介绍（不超过80个汉字）
   - 输入版权信息（不超过10个汉字，默认：debug）
   - 选择标签（最多5个）

8. **提交审核**：
   - 检查所有信息填写完整
   - 点击"提交"按钮
   - 等待提交成功提示

8. **完成发布**：
   - 显示提交成功信息
   - 提示审核周期（通常5个工作日）

### Playwright 操作要点

**登录页面元素**：
- 登录按钮：等待用户扫码
- 登录后跳转到首页

**提交表情页面元素**：
- "提交表情"按钮
- 表情图上传区域（支持多文件上传）
- 每个表情的含义词输入框
- 横幅、封面图、图标上传区域
- 表情名称输入框
- 表情介绍输入框
- 版权信息输入框
- 标签选择区域
- "提交"按钮

**注意事项**：
- 登录需要用户手机微信扫码，无法完全自动化
- 上传文件需要等待上传完成
- 每个步骤需要检查页面状态
- 处理可能的错误提示

## 注意事项

1. 表情单品（1张）暂不支持推广形象、推广信息或人物肖像
2. 同一套表情作品仅可添加至一个表情形象
3. 修改作品所属表情形象仅有1次机会
4. 审核周期通常为5个工作日
5. 上架状态的表情每自然月限用一次修改
